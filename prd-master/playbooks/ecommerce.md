# 电商调研 Playbook

> 本文件是定向查证的资料入口，不是必做清单。只读取能回答当前未决问题的部分；不设竞品数量或数据项配额。已有证据足够即停止。下面的历史数值、市场判断与渠道只是线索，实际使用前必须查证来源、日期及适用范围，不能直接当成当前事实或产品门槛。

## 适用场景

C 端电商平台、自营品牌网店、垂直电商、社交电商、直播电商、内容种草+转化

## 一、按当前问题选择竞品

### 直接竞品

**找法**：
- 京东 / 天猫 / 拼多多 同品类销量榜
- 抖音电商 / 视频号小店 同品类 TOP 主播
- 小红书电商 同品类品牌
- 独立站：用 Shopify Showcase / Built with Shopify 找海外参考
- 行业垂直平台：得物（潮流）/ 闲鱼（二手）/ Boss 直聘（招聘）等

**记录**：
- 品牌名 / 主营品类
- 一句话定位（性价比？品质？设计？速度？）
- 主营 SKU 数量
- 客单价区间
- 月销/年销（淘宝指数、生意参谋公开数据、品牌发布会数据）
- 主流量来源（推断）

### 间接竞品

不卖同样东西但抢同样钱包/同样场景。

## 二、抓商品/店铺页

**用当前环境可用的页面读取能力查看**：
- 店铺/品牌主页（看主推、装修风格、活动）
- 与当前问题相关的商品详情页（看主图、卖点、详情页结构、规格、价格、销量、评价数）
- 直播间链接（如果是直播电商）

**关键字段**：
- 相关主图文案与排列（查看核心卖点排序）
- 商品标题关键词（暴露 SEO 重点）
- 详情页结构（场景图/对比图/工艺图/材质图/检测报告/明星代言/用户评价）
- 规格 SKU（颜色/尺码/型号/数量）
- 客单价 + 促销价 + 历史最低价（阿基米德历史价格查询）
- 销量数 + 评价数
- 累计客户数

## 三、挖差评

### 可选渠道

| 渠道 | 用法 |
|------|------|
| **京东评价** | 商品页 → "好评/中评/差评" 切换看差评 |
| **淘宝问大家** | 商品页 → "问大家" 看用户真实疑问 |
| **小红书** | 搜 `{品牌名} 真实测评` / `{品牌名} 踩雷` / `{品牌名} 退货` |
| **黑猫投诉** | tousu.sina.com.cn 搜品牌名 |
| **B 站** | 搜 `{品牌名} 测评` 看测评 UP 主 |
| **抖音** | 搜品牌名看用户视频 |

### 挖什么

- **质量投诉**：货不对板、做工差、用料差、虚标
- **服务投诉**：发货慢、客服差、退货难
- **物流投诉**
- **价格投诉**：先涨后降、双 11 比平时贵
- **真实使用场景**（看好评和真实测评里用户怎么用）

## 四、行业 Benchmark

### 可能相关的指标

下表机构与报告名称仅作查找线索；实际数值须来自本次取得的真实资料，记录来源、日期、样本和适用范围，不能直接用作项目目标。

| 指标 | 需核对的统计口径 | 查找线索 |
|------|---------|--------|
| **转化率** | 访客、会话或曝光分母，下单或支付事件，品类与渠道 | 艾瑞 / 易观 / 国家统计局电商报告 |
| **客单价 AOV** | 订单或购买用户分母、优惠退款处理与统计周期 | 艾瑞 / 易观 / 国家统计局电商报告 |
| **复购率** | 首购用户群、复购窗口、跨品类购买及用户去重 | 友盟+ / 易观分析 |
| **退货率** | 订单、件数或金额分母，申请或完成退货，品类与周期 | 平台公开资料 |
| **加购转化** | 加购用户或商品分母、下单或支付终点、归因窗口 | 生意参谋 |
| **直播间停留时长** | 人均或单次访问、去重方式、直播时段与流量来源 | 直播观研 / 蝉妈妈 |
| **直播间转化率** | 观看、点击或进店分母，订单或支付终点，主播与品类 | 直播观研 / 蝉妈妈 |
| **种草到转化路径长度** | 内容触达与去重定义、归因窗口、最终转化事件 | 群邑 / 巨量算数 |

### 数据源

- **艾瑞咨询**（电商行业报告）
- **易观分析**
- **国家统计局**电商专题
- **生意参谋**（淘系，需账号）
- **蝉妈妈 / 飞瓜**（抖快直播数据）
- **千瓜数据**（小红书数据）
- **群邑 / 凯度**（消费者洞察）
- **Statista**（全球电商）
- **eMarketer**（全球电商）

## 五、关键判断辅助

### 这个电商生意值不值得做的检查清单

- [ ] 是否有差异化（同质化品类卷不动）
- [ ] 按实际毛利、履约与获客成本判断单位经济模型，不套固定流量成本比例
- [ ] 供应链稳吗（自有工厂/OEM/经销）
- [ ] 复购模型清晰（消耗品最佳，耐用品要靠生态）
- [ ] 流量获取方式（自然搜索/付费投放/达人种草/直播/私域）
- [ ] 客服/物流能扛住峰值（大促爆单怎么办）
- [ ] 合规：食品/药品/医疗器械/化妆品/3C 各有特殊资质

### 中国电商特殊点

- 平台规则博弈：天猫规则 / 京东 PLUS / 抖音直播规则 / 小红书种草规则
- 大促波动巨大：618 / 双 11 / 双 12 / 三八 / 七夕等
- 物流成本：江浙沪发往全国 vs 仓库分布
- 真假货问题：拼多多/直播带货真假识别
- 中差评/差评师/恶意举报对接
- 内容种草是新基建：小红书+抖音+视频号矩阵
- 私域沉淀（企微/社群）是抗平台波动的关键
