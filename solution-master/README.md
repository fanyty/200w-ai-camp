# Solution Master 使用指南

## 这是什么

Solution Master（解题大师）是产品链路的**第零步**，用在写 PRD 之前。

当企业家有一个想法、想解决某个业务问题，但还不知道「这道题该怎么解」时使用。

## 适用场景

✅ **适合用 Solution Master**：
- "我想用AI/数据解决XX业务问题" — 但还没想清楚具体怎么做
- "这个痛点能不能用技术解决" — 需要先验证可行性
- "我看到竞品做了XX，我们能不能做" — 需要先理解背后逻辑
- "我们有很多数据，能做点什么" — 需要先找到决策点

❌ **不适合用 Solution Master**：
- 已有完整、有效且经确认的《解题方案书》 — 核对交接后进入 PRD Master，不重复已完成的解题
- 纯技术问题（"怎么优化数据库性能"）— 这不是业务问题
- 运营/市场问题（"怎么获客"）— 超出设计范围

## 产出物

**《解题方案书》** 包含：
- 控制回路图：要改进的决策、可控变量、结果指标
- 题型判断：属于哪类问题，经典解法是什么
- 行业先例：谁做过、怎么做的、效果如何
- 数据现实：需要什么数据、现在有什么、缺什么
- 2-3条候选路线对比（方法、数据要求、输出形态、风险）
- 推荐路线 + 理由
- 证伪标准：什么情况算失败
- 最小切口：第一步做什么、怎么验证

## 使用方法

### 1. 触发 Solution Master

在对话中说：
- "我有个想法"
- "想用 AI/数据解决……"
- "这个问题该怎么解"
- "解题大师"
- "solution master"

### 2. 准备工作（建议）

**时间**：安排1-2小时专注时间，会问20-30个问题

**材料**（可选但推荐）：
- 最近一次遇到这个问题的具体案例（时间、地点、人物、损失）
- 竞品或参考对象的名字/链接
- 内部以前的尝试和结论

**心态**：
- 诚实回答"不知道"，不要过度承诺
- 不要说"我们没有数据"就放弃，系统会帮你探查隐藏资源
- 如果心中有参考对象（某个公司/产品），一定要说出来

### 3. 流程（自动进行）

```
阶段 0 · 自由倾诉与回放
   ↓
阶段 1 · 问题定型（画出控制回路）
   ↓
阶段 2 · 题型与先例（联网调研）
   ↓
阶段 3 · 数据现实（最关键，最易被跳过）
   ↓
阶段 4 · 解法路线（2-3条对比，你拍板）
   ↓
阶段 5 · 证伪与最小切口
   ↓
阶段 6 · 解题方案书 → 交给 PRD Master
```

### 4. 之后做什么

解题大师会给出《解题方案书》的实际路径和查看方法。下一环节是 PRD Master：
- 方案没问题，回复 **“继续，进入 PRD”**；PRD 会读取同一份方案书，接着衔接 Design 和 TDD，契约完成后再进入开发。
- 需要修改，回复 **“先修改解题方案：……”**；修改后会重新给出查看入口和下一步接续句。
- 用户明确暂停或发现路线不可行时，保留未决项与恢复位置，不把未完成方案当作已通过。

## 核心理念

> **软件不重要。软件是先找到解决方案之后，让方案落地的工具。**

> **没有数据的努力只是点子。任何改进都要走「归因 → 行为 → 结果 → 数据」的循环。**

**先问决策，再问数据，最后问模型。** 不要一上来就说"用大模型做XX"。

## 常见问题

**Q: 我真的没有数据怎么办？**
A: 系统会追问：有没有收银系统？订单系统？CRM？Excel表？很多时候"没数据"只是没意识到有。如果真的没有，会给出"先采集数据"或"用经验规则"的替代方案。

**Q: 我已经知道要做什么了，还需要用吗？**
A: 先核对是否已有完整、有效且经确认的《解题方案书》。有则交接 PRD；没有则把已有想法作为输入，补齐解法、依据与验证方式。知道想做什么、已经写过代码或直接喊“开始 PRD”，都不能代替这份产出。

**Q: 会问哪些问题？**
A: 决策人是谁、多久决策一次、做错的代价、结果指标、可控变量、有没有历史数据、数据在哪个系统、能不能导出、以前有没有做过、见过谁做过、等等。都是为了把问题想清楚。

**Q: 产出的方案书能直接给开发吗？**
A: 不能。方案书是给决策层看的"怎么解"，不是给开发看的"怎么做"。之后需要用 PRD Master 把它细化成产品需求文档。

## 方案书的参考用途

同一份方案书也可供立项、投资或客户沟通参考，帮助核对问题、依据与可行性；这些用途不替代产品链路中进入 PRD 的交接。

## 文件结构

```
solution-master/
├── SKILL.md              # 主技能文件
├── README.md             # 本文件
├── references/           # 参考文档
│   ├── 解题决策树.md     # 节点、依赖、关闭标准（唯一事实源）
│   ├── 追问方法.md       # 苏格拉底式追问技巧
│   ├── 题型库.md         # 常见问题分类和解法
│   ├── 调研指引.md       # 如何联网找先例
│   └── 案例-锦囊.md      # 真实案例
└── templates/
    └── 解题方案书.md     # 最终产出模板
```

## 安装

将整个 `solution-master` 目录放到 `.claude/skills/` 下：

```
.claude/
└── skills/
    └── solution-master/
        ├── SKILL.md
        ├── references/
        └── templates/
```
